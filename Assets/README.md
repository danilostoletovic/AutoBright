# AutoBright icon

Generated with the built-in imagegen tool on 2026-11-05, then copied into this project. The PNG retains transparency. `Build-Icon.ps1` resizes the source into a seven-resolution Windows ICO; Store packaging creates 44, 50 and 150 px PNG assets from the same source.

Final generation prompt:

> Create a polished Windows desktop app icon for AutoBright, a minimal camera-based adaptive laptop screen brightness utility. One bold simple sun symbol integrated into a camera aperture, warm golden amber luminous center, charcoal navy outer aperture, clean dimensional Windows 11 icon craftsmanship with very subtle gradients, instantly legible silhouette at 16 pixels. Centered isolated icon, square 1024x1024 composition, symbol occupies 80 percent of canvas, generous even transparent margins, actual transparent background. No text, letters, watermark, mockup, scene, border, or extra objects. This is the actual production app icon, not a presentation.
